## Дополнительно найденные и исправленные дефекты

- Неверные вложенные JSON-типы могли вызывать исключения вместо quality report.
- Пустые наборы, неверный bonus/threshold/penalty и повторная синергия проходили слабые проверки.
- Дубли JSON-ключей скрывали первое значение; exponent overflow давал бесконечность.
- Дробный лаг исходника молча обрезался до целого.
- Паспорт принимал неверные даты и обратные интервалы.
- Новый паспорт при тех же байтах терялся из-за неполной identity импорта.
- In-memory repository возвращал изменяемые ссылки на сохранённый payload.
- Изменение staging/опубликованного JSON на диске не обнаруживалось при чтении.
- Общий tmp-файл конфликтовал при параллельных записях: теперь имена уникальны.
- Bootstrap с `--store` экспортировал в каталог по умолчанию, а не выбранный.
- Путь ресурса/хранилища предполагал запуск из source checkout.
- Raw engine loader принимал bool/строки/дробные правила и некоторые non-finite числа.

На воспроизводимые дефекты добавлены regression tests. Это не утверждение,
что в проекте больше не осталось ошибок.

## Демо на две минуты

1. Проблема: общий бюджет, пять решений, эффект и компромиссы неочевидны.
2. Каталог: показать синтетический источник, правила, pinned snapshot.
3. Контрольный портфель: 95 бюджета, AQOL 56.54307, вклад среднего/минимума/штрафов.
4. Ошибка: неполный набор или конфликт → понятный отказ и `score: null`.
5. Альтернатива: одна замена → 57.20556 за 100; повторить evaluator для проверки.
6. Evidence: от утверждения перейти к показателю/району/снимку, показать статус AI.
7. Завершить границей: это воспроизводимый тренажёр решения, не реальный городской прогноз.

Ответы жюри: «Почему AI?» — выбирает важные подтверждённые факты, чисел не придумывает;
его добавленная польза пока требует измерения. «Почему доверять?» — правила и исходник
отделены от LLM, есть golden/HTTP/регрессионные тесты. «Масштаб?» — файловое хранилище
локальное; production требует транзакций и нагрузочных измерений.
