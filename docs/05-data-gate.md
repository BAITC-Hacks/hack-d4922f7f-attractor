# Data Gate — загрузка и происхождение данных

## 1. Назначение

Единый путь от файла/API к проверенному снимку города. Данные становятся входом
симуляции только после mapping на сущности и механизмы. Неизвестные поля сохраняются
в raw-слое, но не начинают автоматически влиять на модель.

```text
Источник → raw → проверка → staging → нормализация → quality report
         → preview изменений → публикация immutable snapshot → эксперимент
```

## 2. Каталог данных

| Домен | Примеры | Минимальные единицы/гранулярность | Потребитель |
|---|---|---|---|
| Территория | Границы, здания, адреса | Геометрия, CRS, дата действия | Все модули |
| Население | Возраст, семьи, дети, занятость | Человек/семья, район, дата | Генератор населения |
| Доходы | Распределение зарплат, расходы | Валюта/месяц, базовый период | Домохозяйства |
| Городские финансы | Доходы, трансферты, проекты | Валюта, период, тип проводки | Ledger |
| Экономика страны | Инфляция, занятость, зарплаты | Индекс/процент/валюта, период | Внешние сценарии |
| Транспорт | Сеть, маршруты, расписания, потоки | Метры, минуты, пассажиры/час | Поездки |
| Соцобъекты | Места, штат, обращения | Места, FTE, запросы/день | Очереди |
| ЖКХ и службы | Активы, аварии, бригады | Мощность, состояние, время | Ремонт |
| Среда | Деревья, зелень, воздух, погода | м², штуки, концентрация, температура | Экология |
| Животные | Популяции, приюты, обращения | Численность, места, дата | Специализированный модуль |
| Обратная связь | Обращения и опросы | Канал, время, тема, выборка | Наблюдения |

В файлах различать stocks и flows: «100 обращений за месяц» не означает очередь 100.
Отличать среднее от медианы, валовой доход от располагаемого, людей от домохозяйств.

## 3. Паспорт набора

```yaml
dataset_id: synthetic-city-population
schema_version: '1'
source_type: synthetic  # observed / estimated / synthetic
source_uri: local-fixture
license_or_permission: project-synthetic
retrieved_at: ISO-8601
valid_from: ISO-8601
valid_to: null
geography_version: synthetic-districts-v1
units: people
currency: null
price_base_period: null
checksum: sha256
transform_version: git-revision
missingness_policy: explicit-null
quality_report_id: report-id
```

Паспорт также хранит владельца, ограничения использования, периодичность, lineage,
точность/погрешность при наличии и список применённых преобразований.

## 4. Адаптеры и каналы

Этап 1: CSV, JSON, GeoJSON; затем Parquet и разрешённые API. Таблицы XLSX — отдельный
адаптер с выбором листа и заголовков. Геоданные требуют CRS и валидации геометрии.

Каналы обратной связи: форма приложения, выгрузка контакт-центра, email, бот,
официальный API обращений, разрешённые опросы и публичные источники при наличии права
использования. Канал добавляется отдельным адаптером и контрактом; «все каналы» —
расширяемая архитектура, а не обещание доступа к любой системе.

Обращение содержит source/channel ID, внешний ID, время события и получения,
территорию, тему, статус, основание обработки и confidence классификации. Повторные
сообщения одного инцидента связываются, но обращения разных жителей не теряются.
Реальные обращения и синтетические события сохраняются в разных пространствах.

## 5. Проверки качества

- Схема, тип, обязательные поля, уникальность ключей.
- Ссылочная целостность районов/объектов и географическое покрытие.
- Допустимые диапазоны, единицы и временные интервалы.
- Суммы населения, распределения возрастов, отсутствие отрицательных мощностей.
- Дубликаты, пропуски, выбросы, несовместимые даты и пересечения территорий.
- Задержка поступления и свежесть источника.
- Согласованность валют и ценового периода.

Критическая ошибка блокирует публикацию. Предупреждение требует явной политики
допущения в manifest; импорт не «чинит» неизвестные числа молча. Пропуск не равен нулю.
Импутация сохраняет метод, параметры и флаг estimated на каждом затронутом поле.

## 6. Территории и время

Границы районов версионируются. Перенос исторических данных через изменение границ
требует crosswalk: по населению, площади или адресам с указанием погрешности.
Нельзя просто переименовать старый район и считать данные сопоставимыми.

Сохраняются event time, observed time, ingested time. В прогнозе на дату T разрешены
только данные, доступные на T: это предотвращает утечку будущего через поздние правки.
При обновлении источника запущенный эксперимент продолжает читать свой snapshot.

## 7. Минимальные данные по уровням зрелости

- V1: только предоставленный синтетический источник, без сетевых зависимостей.
- V2-demo: синтетические совместимые население, сеть, объекты, погода и ресурсы.
- V2-calibrated: реальные агрегаты с качеством и историей; независимые данные для теста.
- V2-live: мониторинг свежести, запаздывающие события, reconciliation и защита от
  повторного применения наблюдения. Ассимиляция состояния — отдельная проверяемая
  процедура, а не безусловная перезапись модели каждым входящим сообщением.

## 8. Приёмка Data Gate

Повтор импорта того же файла не создаёт логические дубликаты; checksum и преобразования
воспроизводимы; ошибочная единица/территория блокируется; preview показывает изменения;
rollback переключает ссылку на предыдущий снимок и не уничтожает lineage. Тестовый
snapshot из шести районов поддерживается V2 без изменения исходного V1.
