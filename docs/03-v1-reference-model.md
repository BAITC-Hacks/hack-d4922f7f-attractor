# V1 — точная модель задания

## 1. Источник и неизменяемые правила

Источник: [предоставленный датасет](../data/source-dataset.ru.txt). Канонический
машиночитаемый перевод должен проверяться поле за полем против этого файла.

- Пять районов: Есиль, Алматы, Сарыарка, Байконур, Нура.
- Доли населения: 0.27, 0.24, 0.20, 0.13, 0.16; сумма 1.
- 10 показателей, каждый от 0 до 100; больше — лучше.
- Бюджет 100; остаток не приносит бонуса.
- Ровно 5 разных ID мероприятий; максимум 2 из одного направления.
- У районной меры обязателен один допустимый район, у городской район отсутствует.
- M1 и M3 несовместимы глобально; M4/M7 и M5/M13 — в одном районе.
- Порядок выбора не влияет на расчёт; исходные данные не мутируют.

## 3. Формулы

```text
H = 8 кварталов
r_m = (H − L_m) / H
I'_dk = clip(I_dk + Σ применимых effect_mk × r_m + synergy_dk, 0, 100)
D_d = Σ_k w_k × I'_dk
D_avg = Σ_d pop_d × D_d
N_crit = Σ_d,k 1[I'_dk < 40]
Score = 0.7 × D_avg + 0.3 × min_d(D_d) − N_crit
```

Веса T1,T2,E1,E2,S1,S2,B1,B2,C1,C2:
`0.10,0.10,0.09,0.11,0.11,0.11,0.09,0.09,0.10,0.10`.

Синергии фиксированы и не масштабируются лагом:
M1+M2 → T1 +2 в районе M1; M10+M12 → B1 +2 в районе M10;
M5+M6 → E2 +2 в районе M5. Каждая учитывается один раз.

Сначала суммируются все эффекты, затем clip. Округление только для отображения,
не между шагами. Итоговый Score дополнительно не обрезается до 0–100: такого правила
в условии нет. Время V1 — коэффициент итоговой оценки, а не полноценная траектория.

## 5. Атрибуция и поиск

Точная декомпозиция изменения Score по среднему/минимуму/штрафам всегда доступна.
Вклад отдельной меры нелинеен из-за порогов, минимума, clip и синергий: нельзя
просто сложить изолированные приросты и выдать сумму за атрибуцию портфеля.

Для объяснения показывать непосредственные дельты показателей и marginal effect
удаления меры, явно обозначая, что это диагностический, а не допустимый четырёхмерный
портфель. Опционально точная атрибуция Шепли для 5 мер: 32 подмножества; подмножества
используются только внутренним evaluator без проверки «ровно 5».

Поиск: сначала все допустимые замены одной меры и переносы районной меры; затем
полный перебор C(14,5) = 2002 наборов ID и районных назначений. Пользовательские
ограничения проверяются до ранжирования. Пока полный перебор не завершён, результат
называется лучшим найденным, а не доказанным оптимумом. При равенстве: меньшая цена,
меньше замен, канонический ID. Альтернативы всегда пересчитываются тем же движком.

## 6. Обязательные тесты

Golden: таблица выше с допуском 1e-8. Валидация: 4/6 мер, дубликат, неизвестный ID,
неверный район, городской districtId, бюджет выше 100, превышение категории и конфликты.
Границы: 100 разрешено, ровно 40 не критично, clip после суммирования, синергия один раз.
Свойства: перестановка выбора не меняет результат; запуск не мутирует исходный снимок;
городской эффект одинаково применяется к каждому району; LLM не влияет на числа.

Специальные случаи: M11 в Алматы без компенсации переводит T1 из 40 в 38.25;
M9 в Нуре даёт S1 40.625 и S2 37.625; M7 даёт S1 48; M8 даёт S2 43.75.
Изменение портфеля не обязано всегда менять Score: допустимы численные совпадения.
Проверяется различие специально выбранных сценариев с разными результатами.
