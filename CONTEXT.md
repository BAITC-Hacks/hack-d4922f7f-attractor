# Глоссарий Track 12

## City

Город, доступный в каталоге продукта. В MVP каталог содержит только Астану, но
контракты и ключи кеша всегда используют `city_id`.

## City Definition

Версионированное описание города: районы, показатели, меры, правила симуляции,
карта и источники данных. Не меняется внутри пользовательской сессии.

## Baseline State

Исходный снимок города из датасета до решений пользователя. Сохраняется отдельно
и нужен для сравнения `до / после / дельта`.

## City State

Текущее изменяемое состояние выбранного города в пользовательской сессии. Оно
немедленно пересчитывается после каждой команды и получает новую
`state_revision`; подтверждённая backend-версия может прийти позже.

## State Revision

Монотонный номер изменения `City State`. Он связывает действие пользователя,
отрисованную карту и ответ backend и позволяет отбрасывать устаревшие ответы.

## Scenario Draft

Неподтверждённый набор решений пользователя: выбранные меры, районы и созданные
на карте сценарные объекты.

## Scenario Object

Новый объект, созданный в сценарии: парк, светофор или маршрут. Он не изменяет
исходную геометрию административных районов.

## Scenario Result

Подтверждённый backend результат расчёта для конкретных `scenario_hash` и
`state_revision`: состояния по кварталам, Score, события и audit evidence.

## District

Один из пяти районов игровой модели. Его стабильный `district_id` связывает
геометрию, показатели, меры и реакции агентов.

## Indicator

Один из десяти направленных показателей `0–100`, где большее значение всегда
означает лучший результат.

## Measure

Официальная мера из датасета с областью действия, стоимостью, лагом и эффектами.

## Forecast

Последовательность состояний `Q0…Q8`, рассчитанная по зафиксированной версии
модели. Это сценарный прогноз, а не обещание реального городского результата.

## Council Run

Отдельный запуск AI-совета по уже рассчитанному сценарию. Он объясняет социальные
реакции, но не меняет официальную формулу Score.
