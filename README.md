Репозиторий команды Attractor для хакатона.

## Выбранный трек

Команда выбрала трек **«Аким города»**.

## Docker-окружение

Перед финальной сдачей проект нужно полностью упаковать в Docker, чтобы его можно
было одинаково запускать на компьютерах участников и в среде проверки.

Нужно организовать:

- отдельные Docker-образы для компонентов приложения;
- `Dockerfile` для каждого запускаемого сервиса;
- `compose.yaml` для совместного запуска сервисов и инфраструктуры;
- передачу конфигурации через переменные окружения и файл `.env.example` без
  секретов;
- постоянные тома для данных, которые должны сохраняться между перезапусками;
- проверки готовности и зависимости запуска сервисов;
- единый набор команд для сборки, запуска, остановки и просмотра логов;
- документацию по локальному запуску и требованиям к окружению.

Итоговая проверка должна подтверждать, что проект собирается и запускается с
нуля одной командой Docker Compose.
